# Learn：按已知进度带学

触发：用户要学、复习、理解源码或继续课程。先读学习 Project 状态；仅凭“C++基础”不能假设用户知道 Go 或所有 C++ 特性。

## 步骤

1. 开头简短标明：项目/阶段、当前最小知识点、复习还是新课、此前到哪里、下一步。
2. 确认本轮要能理解或判断什么，先讲它解决的问题；不要展开整套目录。
3. 检查所需前置：新语法、包名、调用形式、参数和关键概念。没讲过且当前必需的先用最小例子解释，再回真实代码。
4. 技术结论按 research 查可靠文档/源码，给出定位；示例、语言规则、实现细节分开。
5. 已学内容用简短结构化复习，不重新机械提问。新课结合真实场景讲机制与边界，再用迁移判断检查理解。
6. 用户要求独立做题：首次只给题目，不提示解法；回答后再分析。答错定位具体规则，不据一次答对标“全部掌握”。
7. 写回实际进度、尚未解释/理解的前置、错题或疑问与下一步；未完成的步骤明确保留。

## 输出

全局位置 → 本轮目标 → 必要前置 → 一个例子/源码片段 → 机制与边界 → 适合的练习或自然接续。

例：讲 Go 指针接收者调用前，先解释接收者与调用语法；不先甩 method set 术语，也不靠未学过的 C++ Lambda 类比闭包。

本协议来自用户明确教学偏好，不声称由已验证的外部教学 Skill 导出；技术查证复用 Research 方法，效果待真实带学反馈。
