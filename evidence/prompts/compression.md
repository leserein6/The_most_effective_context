# 日志压缩 Prompt

输入：{待压缩 current.md 路径}、{本次/下一阶段目标}、{已有定义/规格/决定路径}。
先读完整待压缩原文；关键部分截断必须补读。目标是下一会话可继续，不是把所有细节平均缩短。

输出四个标题：
## 已完成
实际产物、版本、已验证条件和证据路径；部分完成/未验证不能升级为完成。
## 决策
有效决定及用户确认依据；旧决定被替代时注明关系。建议仍标建议。
## 未解决
失败、阻塞、尚未核实的声明及已排除的有价值尝试。
## 恢复位置
下一动作、必需输入/具体位置、对应协议；凭据和隐私不复制进摘要。

已经在规格/代码/决策文档里的完整内容只引用路径，不重复粘贴。检查四部分能否支撑下一阶段，再由主 Agent compact；脚本保留原始日志和哈希，不由摘要生成者删除原文。

参考 S03 的面向接续、引用已有产物和信息脱敏；本地四标题与完整原文保留服从项目管理协议。
