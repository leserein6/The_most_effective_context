# 委派模板：主 Agent 填完后发送

你负责以下唯一子任务。只按本工作包执行，不假设自己看到主会话。

## 输入包

Project ID：{实际ID}
目标：{本项要产生的结果}
职责：{研究/实现/审查，且只能在指定职责内行动}
需求/验收：{明确列项及真实来源路径}
已确认约束：{必须保持的具体值和禁止改变的决定}
背景与输入：{必要文件、版本、已核实事实}
前置依赖：{已满足项、对应产物；未满足则不得开始依赖步骤}
读取范围：{相关文件}
写入范围：{唯一负责文件或worktree；审查则写“只读”}
接口：{依赖和产出的准确签名/字段；不涉及则注明}
交付位置：{实际路径或回传方式}
验证：{可执行检查及成功现象；无运行工具明确说明}

## 执行边界

先核实必需输入可读且任务可执行。关键缺口回报 BLOCKED；不要猜测接口或验收条件。普通实现细节沿用仓库规范。不得修改共享项目状态、擅自扩大范围、派生 Agent 或自动 commit/push。

## 回传

状态：DONE/PARTIAL/BLOCKED/FAILED。
实际成果与路径；改动文件；有意义的操作；命令/检查结果及版本；未验证/剩余项；失败副作用；需要主 Agent 决定的具体问题。
DONE 不是一句成功声明：没有约定证据只能报 PARTIAL/UNVERIFIED。

参考 S09/S10；接口包和共享状态边界为本地适配。
