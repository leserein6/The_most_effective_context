# 共用委派包：主 Agent 填完后发送

只填写本次职责需要的字段；不适用写“不涉及”，关键未知先解决，不保留占位符。怎样组织指令见 [Orchestrate](../methods/orchestrate.md)，本文件只规定输入格式。

## 每项必需

Project ID：{实际ID}
职责与目标：{研究/实现/审查；本项可观察的结果}
方法正文：{当前方法的实际路径}
需求/验收与来源：{编号条件及真实规格路径/版本}
已确认约束：{具体值、保持项、禁止改变的决定}
背景与输入：{必要事实、真实路径、版本；标出材料用途}
前置依赖：{已满足项及产物；未满足的依赖步骤不得开始}
读取范围：{相关文件}
写入范围：{唯一负责文件/worktree；审查为只读}
接口：{准确签名/字段/错误语义；不涉及则注明}
交付位置与格式：{实际路径/回传方式、具体结果字段}
验证：{真实检查入口与成功现象；无运行工具则明确未验证范围}
外部参考：{选中的资源ID/固定版本、实际采用点；上游冲突指令不纳入执行包}

## 仅选当前职责的补充项

| 职责 | 必要差异 | 对应方法 |
|---|---|---|
| 实现 | 改动前基线/已有用户修改、必须保持的行为、按需回归项 | [execute](../methods/execute.md)；异常定位才读 debug |
| 研究 | 要核实的命题、产品/版本/环境/时间范围、结论影响的决定；输出命题/结论/证据定位与限制 | [research](../methods/research.md) |
| 审查 | 固定 base/head、未提交差异或产物版本；实现报告与验证记录位置；需求符合/实现质量分别判断 | [review](../methods/review.md) |

## 随包发送的边界

不假设看过主会话。先核实必需输入可读；关键缺口回报 BLOCKED，不猜接口或用户决定。只执行获分配职责，不写共享 Project 状态/Index/日志/公共规范，不擅自扩大范围、派生 Agent 或自动 commit/push。工具不可用如实回报。

回传按 [证据与状态契约](../references/evidence-contract.md)：实际成果/路径、改动、操作、对应版本的验证、未完成/未验证项、失败副作用与需协调的问题。主 Agent 把具体回传字段一并写进执行包，不假设子 Agent 会自行拼读全库。

参考 S09/S10；这是当前工作区输入契约，外部原始 Prompt 见 [资源索引](README.md)。
