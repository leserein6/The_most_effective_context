# Development Task 测试方法选择协议

**目标：** 从被验证的规格、风险、错误机理推导测试义务，而不是从实现代码反向猜测，也不是按语言/框架套用固定测试清单。

## 1. 先决定要证明的命题

对每一项需求或保留行为，生成稳定 ID 和以下字段：
- 来源：已确认需求、协议、既有行为、风险控制/法规；未知则标 UNRESOLVED，不得暗自补规格；
- **Claim**：明确条件下应成立的可观察性质（含前置条件、输入、输出或状态变化、时序）；
- **Oracle**：正确结果由什么独立来源判定（规格、协议、经确认的实例、数学性质、独立实现）；不能只是被测代码的输出；
- **Impact**：失败后果；**Likelihood/uncertainty**：触发可能性与未知程度；
- **Change surface**：变更触及的输入域、决策、状态、存储、接口、并发、依赖、配置、资源与威胁面；
- 现有可复用证据和其版本、环境、夹具。

如果规格冲突或关键 oracle 缺失，先开展澄清/确认，不能把后续测试绿灯当成已解决。

## 2. 用故障机制选择方法（不是只看风险等级）

| 需求特征 | 优先方法 | 为什么能揭露特定缺陷 |
|---|---|---|
| 输入范围/合法性 | EP + BVA | 错误分区、临界点、off-by-one |
| 多条件规则/拒绝原因 | DT，必要时 BR / MCDC | 遗漏条件组合、短路、条件被忽略 |
| 状态机/重试/乱序 | ST / MBT + 不变量 | 缺失边、非法跃迁、重复事件效果 |
| 事务/数据变更 | DB + 原子性/持久性反例 | 部分提交、丢更新、回滚错误 |
| 并发/幂等 | CON + ST + 必要的 FI | TOCTOU、重复副作用、不可线性化 |
| API/消息结构变化 | CT + 兼容样本 | 旧客户端/消费者语义不匹配 |
| 多配置、多环境、多维输入 | CMB | 参数交互遗漏，先定义有约束的组合 |
| 复杂算法/可写性质 | PROP + MET / DIFF | 单例样本之外的性质反例 |
| 解析器/非可信字节 | FUZZ + BVA + SEC | 非法形状、资源耗尽、崩溃 |
| 外部依赖超时、断连 | FI + ST + REL | 重试/补偿/恢复不能满足不变量 |
| 性能、可用性、权限 | PERF / REL / SEC / ACC | 与对应非功能承诺同尺度的证据 |
| 高风险布尔决策 | DT + MCDC（可行时）+ REV | 证明各独立条件对决策有作用 |
| 测试断言弱或漏检怀疑 | MUT + 独立反例 | 错误变体是否仍能通过 |

这些是**候选方法选择规则**，不是“每个特征自动强制执行全部方法”。对未选、不可执行或过度昂贵的方法，记录成本/前提/风险与替代证据，不静默跳过。

## 3. 决定验证强度

风险决策依据影响、暴露面、不可逆性、可检测/恢复性和知识不确定性（不是仅代码行数）：
- **轻量**：低影响、规格清楚、现有证据可复用。检查变更点、相关回归和必要的局部反例，不机械新建测试；
- **标准**：对用户行为/持久状态产生实质变化。需求→判据→方法→自动测试→独立核对映射；
- **增强**：资金/安全/不可逆数据、对外兼容、跨实例行为、重大性能约束等。额外做失效模式审查、独立 oracle、深层环境/故障/并发证据，并对未验证项升级决策。

等级不是某个覆盖率数字。MC/DC、形式证明或全链路演练是否必要仍取决于具体失效机制与规定；不借“航空做法”要求普通后端全面强制。

## 4. 最小完整方法设计包

每项关键判据至少有以下可复核信息：
1. 反例：哪个**错误实现**应当被这个测试拒绝？
2. 测试模型：边界分区、规则表、状态图、因子矩阵、性质或故障注入点；
3. 具体用例：前置条件、输入/事件、隔离/夹具、预期、观察位置、层级；
4. 目标覆盖项：枚举集合及分母、覆盖路径、不可达/不适用依据；
5. Oracle 独立性：预期来源与实现者是否共享同一未经确认假设；
6. 相反检查：至少针对高风险做“错误实现应失败 + 另一合法实现应通过”（防漏检和误拒）；
7. 尚未验证、资源限制、留待发布阶段的义务。

轻量任务可复用既有计划和测试，但要证明候选版本/配置/规格仍适用。不能仅凭文件名、覆盖率或测试数量宣称充分。

## 5. 渐进式执行与职责

**proposal** 阶段只按需读本页与被触发的方法；形成可审规格与测试模型。**change** 阶段先确认未解决的关键 oracle，再实现并运行。**assess** 使用充分性协议独立审查计划与运行结果。任何 Task 类型都不单独持久化；产物属于业务仓库，摘要与证据索引属于 Project。

可选的标准库辅助命令 scripts/testing_strategy.py 只做**确定性候选方法匹配**，不生成 oracle，不判断业务正确，不自动宣称充分；没有环境时按本页人工执行同一推导。
