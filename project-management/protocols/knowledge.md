# 知识与 Prompt 积累

项目事实、实验结论、领域解释写 notes；参考资料登记 source/INDEX；公共候选写 knowledge-candidates。每条说明来源、适用场景、边界和反例，不能把偶然成功直接升格成通用规范。

Agent 可以自动提炼候选，向用户展示建议纳入内容。用户确认后 promote --confirmed 写 conventions；附真实确认依据和来源 Project。

Prompt 仓库按用途分类。候选 Prompt 先留项目内，用户确认后才修改 evidence/prompts；保留适用目标、输入、输出、验收与变更理由。promote 当前只支持 conventions 的脚本写入；Prompt 文件由 Agent 在确认后修改并审查差异。

资料更新后优先当前权威版本。相互冲突的经验并列注明适用条件，不静默覆盖。敏感配置、令牌、完整隐私材料不放全局积累。
