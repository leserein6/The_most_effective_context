# 项目归属

1. 首先读取 Index。已知锚点可接续；输入、目标或上下文不能唯一锚定时，问用户创建新 Project 还是接续候选。
2. 不通过字符串相似度自动决定归属；脚本只展示索引，语义匹配由 Agent 负责。
3. 判断新建后读取 [Create](create.md)，按其中定义与验收设置步骤执行。对新项目提出名称、三种类型之一、一句话目标。确认后使用 create --confirmed。`--confirmed` 只表示调用者已获得确认，不是脚本检测到了用户意图；必须真实具备会话依据。
4. one_off 表示短、可在单会话内完成、无需跨会话延续的一次性目标；同一会话内可多轮，不能每轮新建。需要跨会话继续的目标不归 one_off。一个消息涉及多个独立项目时，明确每项归属并分别记录，不把项目状态合并。
5. 活跃索引无匹配或用户明确提及非活跃项目时读取 History；归档恢复/重开需确认。
6. 用户已经明确给出全部创建字段并要求创建，视为确认，无需再问相同问题。
