# 项目归属

1. 首先读取 Index。已知锚点可接续；输入、目标或上下文不能唯一锚定时，问用户创建新 Project 还是接续候选。
2. 不通过字符串相似度自动决定归属；脚本只展示索引，语义匹配由 Agent 负责。
3. 判断新建后进入 [Create](create.md)；字段、类型与确认步骤由该协议负责。接续则进入 [Resume](resume.md)，不把每轮消息当作新项目。
4. 一个消息涉及多个独立项目时，明确每项归属并分别记录，不把项目状态合并。
5. 活跃索引无匹配或用户明确提及非活跃项目时读取 History；归档恢复/重开需确认。
6. 归属不明时仅澄清和列选项，不先写 Project；若用户明确确认本轮不建/不归属 Project，可按根入口的“有原因的例外”处理，本轮不 checkpoint，也不把建议冒充已保存。
