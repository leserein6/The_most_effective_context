# Execute / 实施协议

**适用**：实际创建、修改、运行、发布、提交代码或文档等可产生外部结果的任务。

## 执行方法

1. 定义本轮具体交付、可操作范围与验收方式，核实当前资源状态（不要凭空假设文件/权限存在）。
2. 读取相关文件与局部约束；只加载本次修改所需的资料。
3. 以最小必要变更实施，保留已有有效内容；对不可逆、破坏性或超出授权的动作先确认。
4. 执行实际可行的测试/检查；记录已做、未做与失败项，不把“生成文本”等同“已写入”。
5. 回复交付物位置、主要变更、验证结果、限制与必要的下一步。

## 检查点

- 结果是否已经真实写入目标位置？
- 是否存在未经授权的范围扩张？
- 失败后是否把现状说明清楚而不是宣称成功？

若实施涉及长期 Project 的状态变更，另加载 Project 的 **maintain 协议**；不要把本轮临时 Task 当作长期任务记录。
